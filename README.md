# 🌐 Portfolio-V1

## 📖 Overview
This repository contains the source code for my personal portfolio website, originally built in **2025** before I joined **MUET**. It represents one of my early milestones in front-end development and creative technology. The site showcases my skills, projects, and design philosophy at that time, while also serving as a foundation for my growth as a developer and designer.

## ✨ Features
- 🎨 **Elegant Design:** Emerald green and gold palette with smooth micro-interactions (hover effects, scroll animations, splash screen).
- 📱 **Responsive Layout:** Built with **Flexbox** and **CSS Grid**, optimized for multiple screen sizes.
- ⚡ **Interactive Elements:** Custom JavaScript for splash screen, hamburger menu, testimonial slider, and scroll animations using `IntersectionObserver`.
- 🪶 **Lightweight Stack:** Pure **HTML5**, **CSS3**, and **Vanilla JavaScript** — no heavy frameworks.
- 📩 **Contact Form Integration:** Web3Forms API for email submissions.

## 🛠 Technical Highlights
- 🎛 **Custom CSS Variables** for consistent theming.
- 📂 **Modular JavaScript** (though later consolidated for better maintainability).
- ♿ **Accessibility Considerations:** Typography pairing (Montserrat/Raleway), semantic HTML, though some color contrast issues were identified.
- 🚀 **Performance Notes:** Lightweight footprint, but images were originally unoptimized (`.png` format).

## ⚠️ Known Issues (from original build)
- 🌀 Nested media queries in `style.css` caused structural quirks.
- 🌑 Dark green text (`--accent-green`) failed WCAG contrast ratios on dark backgrounds.
- 🖼 Images not optimized for web delivery.
- 📅 Footer year hardcoded (`© 2025`) instead of dynamic.

## 📈 Improvements Since Then
Since building this portfolio, I’ve significantly expanded my skill set in Advanced Front-End development, Graphic designing, programming, and UI/UX Design. 
Future iterations of my portfolio will integrate these skills, modern frameworks, and improved accessibility/performance practices.
